# Expanding the Mathematical Foundations of Artificial Life

Code, data, archives, and animations for the ALIFE 2026 paper:

> **Expanding the Mathematical Foundations of Artificial Life: A Systematic Search Across Function Families, Geometries, and Open Expressions in Lenia**
> Zhe Hong, Mingyang Song — *Proceedings of the Artificial Life Conference 2026 (ALIFE 2026)*, MIT Press.
> 📄 [Camera-ready PDF](ALIFE2026_fp259_camera_ready.pdf)

We systematically expand Lenia's search space along three axes — **function families** (4→28 kernels, 4→16 growth functions), **geometric substrates** (flat, spherical, toroidal, hyperbolic), and **open mathematical expressions** generated by an LLM — and illuminate 291 behavioral niches with MAP-Elites over 125,000+ evaluations.

The central finding: LLM-guided search discovers a growth term `cos(4π · ∇²A)` modulating the growth center — a curvature-coupled term that neither single-kernel Lenia nor the additive multi-kernel form `Σ Gᵢ(Kᵢ * A)` can express, placing it outside the function class standard parametric search explores.

## Materials referenced in the paper

**LLM prompt templates** — `src/llm_search.py` and `src/llm_mutator.py` contain the system, generation, and mutation prompts verbatim. Track B used Claude Sonnet 4 (`claude-sonnet-4-20250514`).

**Complete operation list** — `src/expression_compiler.py` defines every operation exposed to the LLM, including the dual-field high-level operations.

**Archive files** — the MAP-Elites archives are committed as JSON:

| File | Contents |
|---|---|
| `results/archive.json`, `results/archive_final.json` | Unified final archive (291/400 bins) |
| `results/archive_phase1a_4x4.json`, `results/archive_phase1b_flat_only.json` | Staged Track A runs (4 kernels; flat-only) |
| `results/archive_trackB.json` | Track B (LLM) entries |
| `results/archive_localized.json` | Localization / locomotion search |
| `results/archive_8k.json` | 8,000-step re-evaluation |
| `results_cloud/archive_merged.json` | Merged multi-GPU cloud run |

**Animations of the discovered solitons** — `results/gifs/`, `results/gifs_hires/`, `results_localized*/gifs/`, `results_bifurcation/gifs/` (288 GIFs total), including the `cos(4π∇²A)` hero pattern and the `bessel/gaussian_bell` and `morse/relu_like` creatures.

**Per-component computational details**

| Track | Resolution | Steps | Evaluations | Seeded | Hardware | Wall-clock | Cost |
|---|---|---|---|---|---|---|---|
| A (parametric) | 128² | 8,000 | ~125K | 287 | 4× H100 | ~5.5 h | ~$43 |
| B (LLM) | 64² | 2,000 | ~5K | 287 | local + Claude API | ~8 h | ~$15 (API) |
| C (random) | 64² | 2,000 | 1,000 (809 valid) | none | local | — | — |
| Locomotion | 256² | 10,000 | ~15K | none | local | — | — |

Per-track run logs with timing are in `results/track_*_log.txt`.

**Prompt-strategy statistics** — 88% of surviving Track B entries use high-level operations (`curl` / `compete` / `conserve`); hit rates rise from 0.4% to 13.7% under relaxed dual-field prompting. Source logs: `results/track_b*_log.txt`; regenerate with `python analyze_tracks.py`.

**Per-family counts** — of 286 Track A entries, the original 4 Lenia kernels plus the 11 first-expansion kernels account for 82%, and the 13 final-expansion kernels for 18% (11 of 13 produce archive entries). Top new kernels: Morse (7), sech (7), Wendland C2 (6), Riesz (6). FitzHugh-Nagumo leads growth functions with 14 entries. Regenerate with `python analyze_tracks.py`.

## Reproducing

```bash
pip install -r requirements.txt
```

Track A — parametric MAP-Elites:

```bash
python run_search.py --iterations 125000 --archive results/archive.json
```

Track B — LLM-guided expression search (needs an Anthropic API key in the environment):

```bash
ANTHROPIC_API_KEY=... python run_llm_search.py --iterations 1000 --archive results/archive.json
```

Track C — random-grammar baseline:

```bash
python track_c_random_baseline.py
```

Locomotion search:

```bash
python localized_search_v5_broad.py
```

Analysis and rendering helpers: `analyze_tracks.py`, `fair_comparison.py`, `robustness_test.py`, `render_*.py`, `make_creature_gifs.py`.
